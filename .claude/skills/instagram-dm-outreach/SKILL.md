# 인스타그램 DM 아웃리치

시트: https://docs.google.com/spreadsheets/d/1sGWR_-Sap6RBtHcm-mdqIz7PeLQ42YgNkg7E1J7ZCrk (탭 `세일즈보드`)
운영 규칙의 원본은 시트 `기준값` 탭이다. 규칙이 바뀌면 `scripts/dm_queue.py` 상단 상수도 같이 고친다.

## 절대 규칙

1. **컨펌 없이 보내지 않는다.** 초안 전체를 먼저 보여 주고, 사용자가 "ㄱㄱ / 보내" 등으로 승인한 건만 보낸다. 수정 요청이 있으면 고쳐서 다시 보여 준다.
2. **후속 DM 전에 반드시 기존 대화창을 연다.** 상대가 이미 답장했으면 후속 DM을 보내지 않고 `3. 회신 수신`으로 바꾼 뒤 사용자에게 알린다.
3. **계정 보호:** 하루 20건 이하, 건마다 1~3분 간격. 인스타가 "작업 제한", "나중에 다시 시도" 같은 경고를 띄우면 즉시 멈추고 보고한다.
4. 프로필에서 실제로 본 내용만 개인화 문장에 쓴다. 보지 않은 게시물을 본 척하지 않는다.
5. `8. 접촉 중단`, `8. 거절·중단`, 다음 조치에 "보류"가 있는 건은 건드리지 않는다.

## 흐름

### 1) 시트 가져오기
Google Drive 커넥터의 `download_file_content`로 시트를 xlsx로 받는다
(`exportMimeType: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`). 응답의 base64를 디코드해 `book.xlsx`로 저장한다.

### 2) 큐 만들기
```bash
python3 .claude/skills/instagram-dm-outreach/scripts/dm_queue.py book.xlsx --today YYYY-MM-DD
```
- **발송 대기:** `1차 DM`(미접촉) / `후속 DM`(1차 발송 후 3영업일 무응답). 템플릿을 채운 초안이 붙어 나온다.
- **사람 확인 필요:** `직접 대응`(회신 온 건), `발송 여부 확인`(발송 불명), `계정 확인`(URL 없음), `채널 변경·종결 판단`.
- 영업일 계산에 공휴일은 들어가지 않는다. 공휴일이 끼면 사람이 판단한다.

### 3) 초안 다듬기 → 컨펌
- 브라우저로 각 프로필을 열어 최근 게시물·소개를 확인하고, 템플릿 초안 둘째 줄을 실제 본 내용 한 줄로 바꾼다.
- 전체를 한 번에 표로 보여 준다: 번호 · 대상 · @계정 · 단계 · 최종 문구.
- 사용자에게 "전부 / 일부 번호 / 수정"으로 답을 받는다.

### 4) 발송 (Claude in Chrome/Edge, 사용자가 로그인한 브라우저)
건마다:
1. `https://www.instagram.com/<handle>/` 열기 → `메시지 보내기`
2. 기존 대화가 있으면 끝까지 읽고 상대 답장 여부를 확인한다(규칙 2).
3. 승인된 문구를 그대로 입력하고 보낸다. 줄바꿈은 Shift+Enter.
4. 보낸 화면을 캡처해 근거로 남긴다.
5. 다음 건까지 1~3분 기다린다.

### 5) 시트 갱신
보낸 건마다 `세일즈보드` 해당 행을 고친다(원본 폼 탭 `파트너지원`, `출강 상담 신청`, `영업 DB`는 직접 수정하지 않는다).

| 단계 | 발송·접촉 상태 | 회신·진행 상태 | 최근 액션일 | 다음 조치 | 다음 조치 기한 |
|---|---|---|---|---|---|
| 1차 DM | 5. 1차 발송 완료 | 1. 회신 대기 | 오늘 | 3영업일 후 회신 없으면 후속 DM 1회 | +3영업일 |
| 후속 DM | 6. 후속 발송 완료(2차+) | 1. 회신 대기 | 오늘 | 7일 무응답 시 채널 변경(메일·전화) 또는 종결 | +7일 |
| 답장 발견 | (그대로) | 3. 회신 수신 | 오늘 | 24시간 내 답장 + 미팅 제안 | +1일 |

`📈 일일 영업 KPI` 탭의 오늘 행에 인스타 DM 발송 수를 더한다.

## 템플릿

`templates/first_dm.txt`, `templates/followup_dm.txt`. 쓸 수 있는 자리표시자는 `{호칭}`(이름+님), `{분야}`(전문 분야의 마지막 항목), `{주제}`(협업·제안 주제)다.
문구 톤은 시트 `대시보드` 탭의 피치 포인트(수익화 · AI팀 세팅 · 'AI 잘 쓰는 전문가' 브랜딩)를 따른다.
